# 加密解密逻辑（简要）

> 加密文件夹（隐私文件夹）：`/sdcard/InkPlayer/private/`（目录下有 `.nomedia`，媒体库不会扫描）
> 加密方式：AES-256-GCM 加密文件头部 16KB + 后缀改为 `.priv`

## 整体流程

```
选择视频 → 点击"加密" → 文件进入加密文件夹（.priv）
  → 设置页进入"加密文件夹"（验证密码）→ 选择视频 → 点击"取消加密" → 文件还原到 /sdcard/Pictures/
```

## 加密流程

1. 视频列表页长按任意视频，进入多选模式（被长按的文件默认选中，单击切换）
2. 勾选目标视频，点击底部"加密"按钮
3. 首次加密需设置 6 位数字密码（之后每次需验证密码）
4. 后台线程（Coroutine IO）执行：
   - 通过 MediaStore 解析文件真实路径
   - AES-256-GCM 加密文件头部 16KB
   - 移动文件到 `/sdcard/InkPlayer/private/`，改名为 `yyyy-MM-dd_HHmmss_SSS.priv`
   - 删除原文件在 MediaStore 中的记录，防止残留
5. 显示"正在加密..."进度，完成后刷新列表

## 查看加密文件

1. 设置页 → "加密文件夹" → 密码验证（首次进入需设置密码）
2. 验证通过进入加密文件列表（PrivateScreen），按类型区分视频/图片
3. 点击视频可播放：播放时临时解密文件头为临时文件，播放完自动删除，原 `.priv` 文件保持加密
4. 点击图片查看（后续实现）

## 解密流程（取消加密）

1. 加密文件夹内长按任意文件，进入多选模式
2. 勾选目标文件，点击"取消加密"按钮
3. 后台线程执行：
   - 解密文件头部 16KB
   - 通过文件头魔数判断原始格式（MP4/JPEG/PNG 等），确定还原后缀
   - 移动文件到 `/sdcard/Pictures/`，命名为 `ink_yyyy-MM-dd_HHmmss_SSS.原扩展名`
4. 显示"正在取消加密..."进度，完成后刷新列表

## 技术要点

| 项 | 说明 |
|----|------|
| 加密目录 | `/sdcard/InkPlayer/private/`，含 `.nomedia` 防止 MediaStore 扫描 |
| 算法 | AES-256-GCM（带认证的对称加密） |
| 密钥派生 | PBKDF2（HMAC-SHA256，10 万轮迭代 + 固定盐值），从用户密码派生，不存密钥 |
| 加密范围 | 文件头部 16KB（覆盖 MP4 `ftyp`/`moov`、JPEG EXIF、PNG IHDR 等关键数据） |
| 密码验证 | 6 位数字密码，密码哈希存 DataStore；Session 内保持解锁，退出 App 后重新锁定 |
| 权限 | Android 11+ 需要 `MANAGE_EXTERNAL_STORAGE`（所有文件访问） |

## 播放兼容性

- ExoPlayer 通过文件头（`ftyp` box 等魔数）识别容器格式，不依赖后缀名，`.priv` 文件可直接识别
- 加密视频的缩略图由 `MediaMetadataRetriever` 从临时解密文件生成，不依赖 MediaStore
- 还原后的文件重新出现在主列表（MediaStore 重新扫描）
